On this page

Class/task path parsers and short-share helpers for class-id-first dual-read. Mirrors mvtt-server parseClassId / parseTaskId forms.

Accepts forever:

  • classId
  • classId/taskId | classId~taskId
  • teacherEmail/classId[/taskId]
  • local~classId[~taskId]

Writers emit bare classId / classId/taskId (flat classes/{classId}). classPath / taskPath remain for nested legacyPath dual-read fallback only.
